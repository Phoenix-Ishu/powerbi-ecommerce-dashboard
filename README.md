# Rahul's E-Commerce Sales Dashboard

## Overview

This project is an interactive Power BI dashboard created to analyze E-Commerce sales performance, customer behavior, profit trends, and payment methods. The dashboard provides business insights through dynamic visualizations and KPI tracking.

---

## Key Insights

- Clothing and Electronics generated the highest profit.
- COD and Credit Card were the most used payment methods.
- Maharashtra contributed the highest sales amount.
- Profit showed strong performance during the beginning and end of the year.
- Printers and Bookcases were the top profit-generating sub-categories.
